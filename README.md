# PALS Resus Bay

A pediatric resuscitation (PALS) trainer in English and Hebrew: live-monitor code simulations, interactive algorithms, rhythm and dose drills.

**Open it:** https://ofiras.github.io/pals-resus-bay/

Progress is saved in your own browser. For training only, not for clinical decisions.

The site counts anonymous usage (page visits, cases and exams started and finished, language, device type) with simple counters: no cookies and nothing that identifies you. The totals are at https://ofiras.github.io/pals-resus-bay/stats.html
